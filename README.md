# 100 фильмов

Список из 100 фильмов и всех частей их франшиз (175 фильмов). Ставишь галочку после просмотра, и название зачёркивается. Есть поиск, фильтр «Все / Осталось / Просмотрено» и выбор цвета в стиле iOS: фон и акцент, четыре цвета (белый, чёрный, фиолетовый, синий) по шесть оттенков.

Это приложение для Android. Внутри обычная веб-страница (`app/src/main/assets/index.html`), которая открывается в WebView. Интернет для работы не нужен. Отметки и цвета хранятся на самом телефоне.

## Как получить APK

APK собирается автоматически на GitHub.

1. Открой вкладку **Actions** в этом репозитории.
2. Выбери последний запуск **Build APK** с зелёной галочкой.
3. Внизу страницы в разделе **Artifacts** скачай `film100-apk` и распакуй архив. Внутри файл `film100.apk`.
4. Открой файл на телефоне. Android попросит разрешить установку из неизвестных источников для браузера или файлового менеджера. Разреши и установи.

Каждая сборка из ветки `main` автоматически попадает во вкладку **Releases**, оттуда APK скачивается одним нажатием.

Сборка запускается сама при каждом изменении в ветке `main`. Вручную её можно запустить во вкладке Actions кнопкой **Run workflow**.

## Как собрать на компьютере

Нужны Android Studio (или Android SDK 34) и JDK 17.

```
gradle assembleDebug
```

Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`. Проект можно просто открыть в Android Studio.

## Как изменить список

Фильмы лежат в `app/src/main/assets/index.html`, в массиве `GROUPS` в начале скрипта. Каждая строка выглядит так: `["Название", "Original title", год, "id"]`. Поле `id` должно быть уникальным и не меняться, иначе отметки просмотра собьются.

Сборка в этом репозитории подписывается отладочным ключом. Для публикации в Google Play нужен свой ключ подписи.
